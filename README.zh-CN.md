# Simple Badge

[English](README.md) | 简体中文

在 Obsidian 的 Markdown 编辑器中右键，选择 **插入 Badge**，即可预览、创建并按点选顺序批量插入文字 Badge。当前版本：**0.2.0**。

```html
<span class="badge badge-red">重要</span> <span class="badge badge-green">完成</span>
```

插件自带蓝、绿、紫、红四种配色，保持固定的尺寸、圆角和其他外观，无需单独启用 CSS snippet。

## 批量插入

1. 在 Markdown 编辑位置右键，点击 **插入 Badge**。
2. 左侧显示渲染后的预设。点击前面的圆形按钮，按钮显示从 1 开始的选择顺序。
3. 继续选择其他预设；再次点击已选按钮会取消选择并重新编号，重新选中则追加到末尾。
4. 下方的“插入顺序”显示本次选择，也可以点击其中的条目移除。
5. 点击右下角的 **插入选定 Badge**，一次性插入完整的 span，相邻 span 之间使用一个空格。

每次正常打开窗口都默认不选择任何 Badge。取消或按 Esc 关闭窗口不会插入文本。

## 现场创建

在窗口右侧填写文字、选择颜色，预览会立即更新。

- 点击 **加入本次选择**：作为临时 Badge 追加到本次插入顺序。
- 勾选 **同时保存为预设**，再点击 **加入选择并保存预设**：同时保存到左侧预设列表，下次打开仍可使用。
- 保存操作立即生效；之后取消插入窗口不会撤回已经保存的预设。
- 文字不能为空，首尾空白会被去除。文字按纯文本处理，`&`、`<`、`>` 在 HTML 中自动转义。
- 相同文字和相同颜色会复用已有条目，不会在一次选择中重复加入；相同文字但不同颜色可以分别保存。

## 配置预设

打开 Obsidian **设置 → 第三方插件 → 已安装插件 → Simple Badge 右侧的 ⋮ → 设置**。也可以从设置侧栏“第三方插件”分类下直接点击 **Simple Badge**。入口样式可能随 Obsidian 版本变化。

配置页支持新增、编辑、删除、上移和下移，所有条目都显示渲染后的预览。列表顺序只影响展示，实际插入顺序始终由本次点选决定。

首次使用提供四个示例预设：信息（蓝）、完成（绿）、备注（紫）、重要（红）。可以修改或全部删除；主动清空后不会自动恢复默认值。

预设保存在当前 vault 的 `.obsidian/plugins/simple-badge/data.json`。保存失败时会显示错误并保留输入；后续可以重试。配置格式损坏或来自不支持的版本时，插件会提示检查文件，不会用默认值覆盖原配置。

修改、删除预设不会修改笔记中已有的 span，也不会悄悄改变已经打开的插入窗口中的选择。

## 编辑行为

- 支持桌面端源码模式和实时预览模式的 Markdown 编辑器右键菜单。
- 使用打开右键菜单时的主光标位置；存在选区时保留原文，在主选区末尾插入。
- 除相邻 span 之间的一个空格外，不额外添加空格、换行或占位文字。
- 插入后光标位于整个批次之后，一次撤销或重做处理整个批次。
- 窗口打开后原文发生变化，或原编辑器已失效时，点击插入会提示 **重新定位**。点击该按钮后，在新的位置右键打开插入窗口即可继续使用保留的选择和草稿。
- 重新定位暂存仅保留在内存中；取消新窗口、停用插件或退出 Obsidian 会结束该次操作。
- 阅读模式显示渲染后的 Badge；编辑模式沿用 Obsidian 原生的行内 HTML 行为。
- 停用插件后笔记中的 HTML 保留。需要独立保留配色时，可将 `styles.css` 开头的 `.badge` 和四个颜色规则复制到 CSS snippet 中启用。

## 开发与测试

需要 Node.js 20+ 和 pnpm。

```sh
pnpm install
pnpm build
pnpm test
```

`pnpm dev` 监听源码并重新构建；`pnpm typecheck` 单独检查类型。开发监听不会自动同步或重载 vault 中的插件。

13 项自动化测试覆盖选择顺序、取消与重新选择、选择快照、特殊字符、批量编辑事务、默认与空配置、重复项、预设增删改排序、重载、并发保存和保存失败恢复。

已在 Windows Obsidian **1.13.7** 的 Develop vault 中实际验证：带编号的多选、取消后重排、临时与已保存 Badge 混合插入、HTML 转义、整批撤销与重做、设置页增删改排序、插件重新启用后的预设保留和单一右键入口，以及原文变化后保留选择并重新定位插入。示例保留在 vault 的 `Simple Badge 示例.md`。

清单最低 API 版本为 1.1.1；旧版本、其他主题及移动端没有完成实际界面验证，当前插件仅声明支持桌面端。旧版内置浏览器若不支持 `color-mix()`，会保留基础 Badge 背景。

## 部署与安装

```sh
pnpm build
pnpm run deploy:dev
```

上述命令将 `main.js`、`manifest.json`、`styles.css` 部署到：

```text
D:\Notes\Develop\.obsidian\plugins\simple-badge
```

其他 vault：

```sh
pnpm run deploy "D:/path/to/vault"
```

在 Obsidian 的“设置 → 第三方插件”中启用 **Simple Badge**。更新后关闭再开启该插件。

也可以将 `simple-badge-0.2.0.zip` 中的三个文件解压到目标 vault 的 `.obsidian/plugins/simple-badge/` 后启用。更新时保留已有的 `data.json`。

部署脚本只复制三个插件文件，不改写预设数据、启用列表或其他插件配置。

## 源码结构

- `src/main.ts`：右键入口、编辑位置校验与插件生命周期。
- `src/insert-modal.ts`：预设选择、创建和批量插入窗口。
- `src/settings.ts`：官方设置页与预设编辑窗口。
- `src/badge-form.ts`：两类窗口共用的文字、颜色和预览表单。
- `src/model.ts`：预设类型、配置校验、选择顺序和 HTML 序列化。
- `src/preset-store.ts`：预设操作与串行持久化。
- `src/badge.ts`：安全的 DOM 预览与编辑器批量事务。
- `styles.css`：Badge 固定样式及插件界面布局。
- `tests/core.test.mjs`：核心行为测试。
- `scripts/deploy.mjs`：复制构建产物到指定 vault。
