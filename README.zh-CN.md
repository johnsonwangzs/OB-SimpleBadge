# Simple Badge

[English](README.md) | 简体中文

在 Obsidian 的 Markdown 编辑器中右键，选择 **插入 Badge**，即可预览、创建并按点选顺序批量插入文字 Badge。当前版本：**0.6.0**。

```html
<span class="badge badge-red">重要</span> <span class="badge badge-green">完成</span>
```

插件提供八种主题色和任意自定义 HEX 颜色，支持统一调整字号比例，内边距随字号缩放，圆角、边框及 15% 的半透明背景保持固定，无需单独启用 CSS snippet。

插件界面跟随 Obsidian 的语言：中文语言设置使用简体中文，其他语言使用英文。翻译覆盖菜单、弹窗、设置、颜色名称、状态提示和辅助朗读标签。

如需使用英文，在 Obsidian 的 **设置 → 关于 → 语言** 中选择 **English**，然后按提示重新启动。切换语言会保留已经保存的预设文字。

## 调整字号

打开 **设置 → Simple Badge → 外观 → Badge 字号比例**，拖动滑块或输入整数百分比。范围为 **50%–150%**，步长为 **1%**；默认 **72%**，与旧版的 `0.72em` 一致。点击重置按钮可恢复为 72%。新版 Obsidian 设置搜索支持“字号”“比例”和 `font` 等关键词。

该设置保存在当前 vault 中，统一应用于预设列表、新建与编辑预览、插入顺序、span 导入预览，以及笔记和 Canvas 中已经存在或新插入的 Badge。各处使用同一比例，实际字号跟随周围文字：例如 80% 在 16px 正文中为 12.8px，在 24px 标题中为 19.2px。源码模式中的 HTML 代码文本仍使用编辑器字号。

调整会立即更新主窗口及独立窗口中的渲染结果，无需重新插入、刷新笔记或重启。连续调整合并保存；输入不完整或不在范围内时保留最近有效效果，离开输入框后提示错误。保存失败时提示并恢复最近成功保存的比例。关闭设置页会提交最后的有效值。

字号不写入单个预设或 span，调整不会改写笔记。复制 Badge 到其他 vault 后，使用目标 vault 的字号比例。

## 选择颜色

插入窗口中新建 Badge，以及设置页中新增、编辑预设，都使用同一个颜色选择器。

- **主题色**：红、橙、黄、绿、青、蓝、紫、粉。色块展示当前主题下的实际颜色，勾选标记表示当前选择；颜色随 Obsidian 主题自动适配。
- **自定义**：点击颜色方块打开原生取色器，或者直接输入 HEX。取色器、输入框和 Badge 预览同步更新；自定义颜色在切换主题时保留指定色值。
- 支持 `#RRGGBB` 和 `#RGB`，兼容大小写及首尾空格，保存时统一为小写六位格式。因此 `#ABC` 和 `#aabbcc` 视为同一种颜色。暂不接受透明度及其他 CSS 颜色表达式。
- HEX 尚未输入完整或无效时，预览保留上一次有效颜色，暂时禁止保存或添加该草稿；离开输入框后显示格式提示。输入过程中不会自动展开简写，便于连续输入六位色值。

主题色保留现有的纯 class HTML 格式。自定义 Badge 将色值保存在 CSS 变量中，复制 span 到其他笔记时颜色信息会一同保留：

```html
<span class="badge badge-custom" style="--simple-badge-color: #e67e22;">重要</span>
```

两种格式的基础外观均由插件样式提供。

## 批量插入

1. 在 Markdown 编辑位置右键，点击 **插入 Badge**。
2. 左侧显示渲染后的预设。点击前面的圆形按钮，按钮显示从 1 开始的选择顺序。
3. 继续选择其他预设；再次点击已选按钮会取消选择并重新编号，重新选中则追加到末尾。
4. 下方的“插入顺序”显示本次选择，也可以点击其中的条目移除。
5. 点击右下角的 **插入选定 Badge**，一次性插入完整的 span，相邻 span 之间使用一个空格。

每次正常打开窗口都默认不选择任何 Badge。取消或按 Esc 关闭窗口不会插入文本。

## 现场创建

在窗口右侧填写文字、选择颜色，预览会立即更新。

- 点击 **加入本次选择**：作为临时 Badge 追加到本次插入顺序。
- 勾选 **同时保存为预设**，再点击 **加入选择并保存预设**：同时保存到左侧预设列表，下次打开仍可使用。
- 保存操作立即生效；之后取消插入窗口不会撤回已经保存的预设。
- 文字不能为空，首尾空白会被去除。文字按纯文本处理，`&`、`<`、`>` 在 HTML 中自动转义。
- 相同文字和相同颜色会复用已有条目，不会在一次选择中重复加入；相同文字但不同颜色可以分别保存。

## 配置预设

打开 Obsidian **设置 → 第三方插件 → 已安装插件 → Simple Badge 右侧的 ⋮ → 设置**。也可以从设置侧栏“第三方插件”分类下直接点击 **Simple Badge**。入口样式可能随 Obsidian 版本变化。

配置页支持新增、编辑、删除、上移和下移，所有条目都显示渲染后的预览。列表顺序只影响展示，实际插入顺序始终由本次点选决定。

Obsidian 1.13.0 及以上版本支持通过设置搜索找到“新增预设”和 span 导入入口，也可以按预设文字或颜色搜索各个预设；搜索 `span` 即可找到导入入口，修改后搜索结果会同步更新。Obsidian 1.8.7–1.12.x 使用标准设置页，不提供搜索集成。

首次使用按界面语言提供四个示例预设：中文为信息（蓝）、完成（绿）、备注（紫）、重要（红）；英文为 Information、Done、Note、Important。可以修改或全部删除；主动清空后不会自动恢复默认值。已经保存的预设不会被自动翻译。

预设与字号比例保存在当前 vault 的 `.obsidian/plugins/simple-badge/data.json`。预设保存失败时会显示错误并保留输入；后续可以重试。配置格式损坏或来自不支持的版本时，插件会提示检查文件，不会用默认值覆盖原配置。

0.6.0 可读取版本 1、2、3 的配置数据。版本 1、2 自动补充默认字号比例 72%，保留已有预设 ID、文字、颜色和顺序；下一次成功修改字号或保存预设时写入版本 3，单纯加载不会改写文件。0.5.0 及更早版本无法读取版本 3 数据，如需降级，请提前备份 `data.json`。

修改、删除预设不会修改笔记中已有的 span，也不会悄悄改变已经打开的插入窗口中的文字与颜色选择。全局字号比例会同步应用于这些 Badge 的显示。

## 从 span 代码添加预设

需要复用其他 vault 中的 Badge 时，从 Markdown 源码中复制完整的 span，然后打开 **设置 → Simple Badge**。在 **新增预设（Add preset）** 下方找到 **从 span 代码添加预设（Add presets from span code）**，点击右侧的 **添加预设（Add presets）** 按钮。

1. 在弹窗中粘贴一个或多个 span，以空格或换行分隔。也支持用 Markdown 代码块包裹，语言为空或 `html` 均可。
2. 检查渲染后的预览，以及将新增和跳过的条目数量。
3. 点击 **添加预设**，所有新 Badge 按粘贴顺序追加到列表末尾，立即可用于插入，也可以像其他预设一样编辑。

例如，一次粘贴下面两行即可添加一个主题色 Badge 和一个自定义颜色 Badge：

```html
<span class="badge badge-red">重要</span>
<span class="badge badge-custom" style="--simple-badge-color: #e67e22;">复查 &amp; 确认</span>
```

相同文字和颜色的条目自动跳过，同一批代码内部的重复项也会去重。`#ABC` 和 `#aabbcc` 等等价 HEX 值视为同色。已有预设保留原来的 ID 和顺序；如果全部重复，添加按钮不可用。

支持 Simple Badge 的八种主题色类和自定义 HEX 格式。HTML 实体会还原为文字，例如 `&amp;` 还原为 `&`，`&lt;` 还原为纯文字 `<`。Badge 文字必须非空且为单行。其他 HTML 标签、额外属性和其他 CSS 声明会被拒绝；该功能导入的是 Badge 的文字与颜色，不会迁移任意 CSS snippet 或主题设置。主题色遵循目标 vault 的主题，自定义 HEX 色值保持一致。

遇到无效 span 时，弹窗会指出它在批次中的位置，全部代码有效后才能添加。取消不会改动预设。单次最多接受 500 个 Badge、200,000 个字符；整批预设通过一次保存操作写入，失败时保留输入，便于重试。

## 编辑行为

- 支持桌面端源码模式和实时预览模式的 Markdown 编辑器右键菜单，包括 Canvas 文本卡片。双击卡片进入编辑状态，再在卡片文字区域内右键，选择 **插入 Badge**。卡片外框菜单和画布空白处菜单不提供该操作。
- 使用打开右键菜单时的主光标位置；存在选区时保留原文，在主选区末尾插入。
- 除相邻 span 之间的一个空格外，不额外添加空格、换行或占位文字。
- 插入后光标位于整个批次之后，一次撤销或重做处理整个批次。
- 窗口打开后原文发生变化，或原编辑器已失效时，点击插入会提示 **重新定位**。点击该按钮后，在新的位置右键打开插入窗口即可继续使用保留的选择和草稿。
- 重新定位暂存仅保留在内存中；取消新窗口、停用插件或退出 Obsidian 会结束该次操作。
- 阅读模式显示渲染后的 Badge；编辑模式沿用 Obsidian 原生的行内 HTML 行为。
- 停用插件后笔记中的 HTML 保留。需要独立保留配色时，可将 `styles.css` 开头的 `.badge`、八个主题色规则及 `.badge-custom` 规则复制到 CSS snippet 中启用。

## 部署与安装

```sh
pnpm build
pnpm run deploy:dev
```

上述命令将 `main.js`、`manifest.json`、`styles.css` 部署到：

```text
D:\Notes\Develop\.obsidian\plugins\simple-badge
```

其他 vault：

```sh
pnpm run deploy "D:/path/to/vault"
```

在 Obsidian 的“设置 → 第三方插件”中启用 **Simple Badge**。更新后关闭再开启该插件。

也可以将 `simple-badge-0.6.0.zip` 中的三个文件解压到目标 vault 的 `.obsidian/plugins/simple-badge/` 后启用。更新时保留已有的 `data.json`。

部署脚本只复制三个插件文件，不改写预设数据、启用列表或其他插件配置。

## 源码结构

- `src/main.ts`：右键入口、编辑位置校验与插件生命周期。
- `src/appearance.ts`：字号即时预览、合并保存、失败恢复及各窗口的全局 CSS 变量。
- `src/font-size-control.ts`：共用的字号滑块、百分比输入、重置与状态提示。
- `src/editor-target.ts`：记录原编辑器和光标，为笔记及嵌入式编辑器校验插入目标。
- `src/i18n.ts`：英文、简体中文文案及语言识别。
- `src/insert-modal.ts`：预设选择、创建和批量插入窗口。
- `src/settings.ts`：官方设置页与预设编辑窗口。
- `src/import-modal.ts`：span 导入窗口、校验提示与渲染预览。
- `src/span-import.ts`：完整 Badge span 的严格解析与 HTML 实体还原。
- `src/badge-form.ts`：两类窗口共用的文字、颜色和预览表单。
- `src/color-picker.ts`：共用的主题色块、原生取色器和带校验的 HEX 输入。
- `src/model.ts`：预设类型、配置校验、选择顺序和 HTML 序列化。
- `src/preset-store.ts`：预设操作与串行持久化。
- `src/badge.ts`：安全的 DOM 预览与编辑器批量事务。
- `styles.css`：Badge 全局样式及插件界面布局。
- `tests/core.test.mjs`：核心行为测试。
- `tests/appearance.test.mjs`：字号校验、配置迁移、保存并发、失败恢复及多窗口样式生命周期测试。
- `tests/import.test.mjs`：span 解析及批量导入测试，通过同一测试命令运行。
- `scripts/deploy.mjs`：复制构建产物到指定 vault。
- `THIRD-PARTY-NOTICES.txt`：内置 HTML 实体解码库的许可声明，构建时也会写入 `main.js`。
